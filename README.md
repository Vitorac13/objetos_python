# objetos_python

Repositório com exemplos e exercícios sobre orientação a objetos em Python.

## Conteúdo

- classes básicas (construtores, métodos, atributos)
- encapsulamento e propriedades
- herança e polimorfismo
- exemplos práticos e pequenos exercícios

## Requisitos

- Python 3.8+

## Como usar

1. Clone o repositório:
	git clone <repo-url>
2. Navegue até a pasta do projeto:
	cd objetos_python
3. Execute os scripts de exemplo com:
	python nome_do_arquivo.py

## Estrutura sugerida

- src/         -> código fonte com exemplos
- tests/       -> testes (opcional)
- docs/        -> documentação adicional
